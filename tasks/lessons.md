# 项目经验

## 2026-04-02

- 这个仓库做前端构建前，必须先执行 `nvm use 8.17.0`，不要直接使用当前系统 `node` 版本。
- 遇到旧版 `webpack`/`typescript` 工具链时，先核对仓库说明里的 Node 版本要求，再开始验证，避免把环境问题误判成代码问题。
- 用户已明确纠正：当前协作中不要为了验证去切换到低版本 Node；若仓库说明与用户要求冲突，优先遵循用户指定的当前 Node 环境，并把环境兼容性作为验证结果的一部分单独说明。
- 用户在 GPU/浏览器排查中给出的测试性 `flag`、启动参数或临时实验设置，不能直接当作根因；需要先确认它们是否只是用户为复现/测试临时加上的配置，再决定是否纳入最终结论。
